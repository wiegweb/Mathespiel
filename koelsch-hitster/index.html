So wird jespillt

  1. Jedes Team startet mit einer aufgedeckten Karte auf seinem Zeitstrahl.
  2. Wer dran ist, bekommt eine verdeckte Karte und der Song läuft automatisch an (30 Sekunden). Falls das Handy nicht von selbst startet: einmal auf ▶ tippen. Im Quiz-Modus stehen Interpret und Titel zusätzlich auf der Karte.
  3. Das Team tippt auf die Lücke im eigenen Zeitstrahl, wo der Song hingehört. Richtig: Karte bleibt liegen. Falsch: Karte ist weg.
  4. Im Hör-Modus gibt es eine Kamelle 🍬, wenn Interpret und Titel richtig genannt wurden. 1 Kamelle = Song überspringen, 3 Kamelle = eine Karte geschenkt.
  5. Wer zuerst die Zielzahl an Karten hat, gewinnt. Gleiche Jahre dürfen nebeneinander liegen.
